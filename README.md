## Проект тестирования API ЯндексСамокат 
### В файле urls созданы все ручки используемы в тестах
### В файле data создан класс CourierData в котором генерируются креды для курьера
### В файле api_methods созданы метода вызова всех ручек используемых в тестах
### В файле test_create_courier созданы тесты:
#### test_successful_create_courier в котором проверяется успешная регистрация курьера со всеми необходимыми данными, с помощью получения кода и тела ответа
#### test_create_courier_without_required_parameter в котором проверяется, что при попытке создания курьера без одного из обязательных параметров, возвращается ошибка(код и тело ответа)
#### test_create_two_identical_courier в котором проверяется, что при попытке создать двух одинаковых курьеров, возвращается ошибка(код и тело ответа)
### В файле test_create_order созданы тесты:
#### test_successful_create_order_with_different_color в котором с использованием параметризации проверяется создание заказа с разными данными в параметре color(grey, black, оба цвета, без параметра) - код ответа и наличе track в теле ответа
### В файле test_login_courier созданы тесты:
#### test_successful_login_courier в котором проверяется успешная авторизация курьера(код ответа и наличие id в теле ответа)
#### test_login_courier_without_required_parameter в котором проверяется, что при попытке авторизации без одного из параметров возвращается ошибка(код и тело ответ)
#### test_login_courier_with_incorrect_login в котором проверяется, что при попытке авторизации с некорректным логином возвращается ошибка(код и тело ответ)
#### test_login_courier_with_incorrect_password котором проверяется, что при попытке авторизации с некорректным паролем возвращается ошибка(код и тело ответ)
### В файле test_order_list созданы тесты:
#### test_get_courier_order_list в котором проверяется метод получения списка заказов курьера(предварительно создается заказ и принимается курьером) - код ответа и то что id ранее принятого заказа есть в ответе
